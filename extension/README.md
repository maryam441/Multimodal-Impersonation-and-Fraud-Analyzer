# Sentinel Ambient Shield — Chrome / Edge Browser Extension (v3.0.0)

Real-Time Ambient Fraud & Authority Impersonation Guardian for WhatsApp Web, Gmail, and Web Browsing with Human-in-the-Loop 1-Click FIA Cybercrime Reporting.

## 🚀 15-Second Installation Guide

### For Google Chrome & Brave:
1. Open Google Chrome and navigate to:
   ```
   chrome://extensions/
   ```
2. In the top-right corner, toggle **Developer mode** to **ON**.
3. Click the **Load unpacked** button in the top-left toolbar.
4. Select the `fyp/extension` directory from your computer:
   ```
   c:\Users\Maryam_Sharif\Desktop\fyp\extension
   ```
5. Click **Select Folder**. The **Sentinel Ambient Shield** icon (🛡️) will appear in your browser extensions bar!

### For Microsoft Edge:
1. Open Microsoft Edge and navigate to:
   ```
   edge://extensions/
   ```
2. In the left sidebar, toggle **Developer mode** to **ON**.
3. Click **Load unpacked** and select the `fyp/extension` folder.
